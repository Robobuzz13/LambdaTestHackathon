# 🚀 Selenium Automation Framework with LambdaTest Integration

A scalable Selenium TestNG automation framework built with Java. It supports cross-browser testing with LambdaTest, parallel execution, detailed reporting, driver factory pattern, re-running failed test cases, and logging.

---

## 🛠 Tech Stack

- **Java 18**
- **Maven**
- **Selenium 4**
- **TestNG 7**
- **ExtentReports 5**
- **Log4j 2**
- **LambdaTest (Cloud Grid Integration)**
- **Factory + Abstract Factory Pattern (Driver Management)**

---

## ✅ Key Features

- Cross-Browser Testing with LambdaTest Grid

- Parallel Test Execution using TestNG and Thread-safe WebDriver management

- Configurable Test Environments through .properties files

- Driver Factory Pattern for environment and browser flexibility

- Structured Logging using Log4j

- HTML Reporting using ExtentReports

- Re-run Failed Tests via TestNG rerun mechanism

---

## 🔧 Configuration

### 1. Environment Variables

Set your LambdaTest credentials as environment variables:

- export LT_USERNAME=your_username
- export LT_ACCESS_KEY=your_access_key

Or pass them via Maven command:

- mvn clean test -DLT_USERNAME=your_username -DLT_ACCESS_KEY=your_access_key

### 2. Properties File

Located at src/main/resources/config/lambdatest.properties, used to store test URLs, login credentials, and other test data.

---

## 🧪 Running Tests

### Run All Tests:

mvn clean test

### Run with Specific Browser and Environment:

- mvn clean test -Dbrowser=CHROME -Denvironment=LAMBDA_TEST

### Parallel Execution:

- Defined in smoke.xml using <suite parallel="tests" thread-count="2">

---

## 📋 Reports

### HTML report generated by ExtentReports under /reports directory.

Logs saved in /logs using Log4j.

---

## 🔁 Re-running Failed Tests

Using RetryListener for re-running only the failed tests.

---

## 🏗️ Design Patterns Used

### Driver Factory Pattern

Abstract Factory and Factory pattern used to handle WebDriver instantiation based on:

- EnvironmentType (LOCAL / LAMBDA_TEST)

- BrowserType (CHROME / FIREFOX / EDGE)

ThreadLocal ensures thread-safe driver usage during parallel execution.
